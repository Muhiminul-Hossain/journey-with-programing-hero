# Journey with Programming Hero 🚀

## Overview

This repository is my learning journey through the Programming Hero full-stack web development course. It holds my JavaScript practice files, small tasks, and exercises. I add to it as I learn new topics.


## Technologies Used

- JavaScript
- HTML

## Features

- JavaScript practice files
- Conditionals (if-else) practice tasks
- Loops practice
- Arrays practice
- Strings and objects practice
- Mini tasks and exercises with notes in Markdown files

## Dependencies

There are no external dependencies. This project uses plain JavaScript and HTML.

To run the `.js` files from the terminal, you need [Node.js](https://nodejs.org/) installed. This is optional, because you can also run the code in the browser console.

## How to Run Locally

1. Clone the repository:
```bash
   git clone https://github.com/Muhiminul-Hossain/journey-with-programing-hero.git
```
2. Go into the project folder:
```bash
   cd journey-with-programing-hero
```
3. Open `index.html` in your browser.
4. To run a JavaScript file with Node.js:
```bash
   node array_practise.js
```
